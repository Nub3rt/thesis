\part{Conclusion}
\label{sum}

In this thesis, I have designed a model that can simulate a game of Terraforming Mars. This layer was designed following the object-oriented paradigm and is also event driven. I implemented subsystems like \textbf{Board} or \textbf{Deck} that store and offer data encapsulated by them. The model is a standalone library, that is independent of the view and can be used as a backend for other view implementations.

I created a user-friendly application in OpenGL for players to parttake in their hobby of playing Terraforming Mars. The application lets the user concentrate on their strategy without having to count and manage resources and keep track of effects, as these are automated by the application. It also provides smooth and appealing visuals to immerse the players in the world of Terraforming Mars.

There are numerous possible features to be implemented. Here are a few that I consider implementing in the future.
\begin{itemize}
    \item Implement all cards of the basic set and the 'Corporate Era' cards.
    \item Implement multiple boards to choose from.
    \item Give feedback about why a card cannot be played.
    \item Solve the problem with the state that requires the \texttt{Update} method in \textbf{GameModel}.
    \item Implement online multiplayer.
    \item Add extension packs.
\end{itemize}
